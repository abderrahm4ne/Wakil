# Wakil

Wakil is a Next.js platform for configuring customer-support bots for Facebook Pages and Instagram business accounts. It includes account management, subscription billing, bot settings, rule-based responses, AI-powered response configuration, analytics, conversation history, and Meta channel connection.

## Current status

The application is under active development. Authentication, dashboard, billing, bot configuration, analytics, channel connection, and the Meta OAuth page picker are implemented. Receiving and replying to Facebook or Instagram messages is not yet a finished feature; do not treat the channel connection as a production messaging integration yet.

## Stack

- Next.js 16 and React 19
- TypeScript and Tailwind CSS
- PostgreSQL and Prisma
- Auth.js with credentials and Google sign-in
- Stripe subscriptions
- Resend transactional email
- Meta Graph API for Facebook and Instagram account connection
- Vercel for deployment

## Prerequisites

- Node.js 20 or later
- A PostgreSQL database
- A Meta developer app, if testing channel connection
- Accounts and API keys for any enabled optional services: Google OAuth, Resend, Stripe, Gemini, or Anthropic

## Local setup

1. Install dependencies.

   ```bash
   npm install
   ```

2. Copy `.env.example` to `.env.local` and fill in the required values.

3. Apply the database migrations.

   ```bash
   npx prisma migrate deploy
   ```

4. Generate the Prisma client if it was not generated by the install hook.

   ```bash
   npx prisma generate
   ```

5. Start the application.

   ```bash
   npm run dev
   ```

Visit `http://localhost:3000`.

| Variable | Purpose |
| --- | --- |
| `DATABASE_URL` | PostgreSQL connection string. |
| `NEXTAUTH_SECRET` | Long, random secret used by Auth.js. |
| `NEXTAUTH_URL` | Canonical application URL. |
| `NEXT_PUBLIC_BASE_URL` | Public application URL used for the Meta OAuth callback. |
| `ENCRYPTION_KEY` | Long random secret used to encrypt stored channel access tokens and sign OAuth state. |
| `GOOGLE_CLIENT_ID` | Google OAuth client ID. |
| `GOOGLE_CLIENT_SECRET` | Google OAuth client secret. |
| `RESEND_API_KEY` | Resend API key for verification email. |
| `META_APP_ID` | Meta app ID. |
| `META_APP_SECRET` | Meta app secret. |
| `META_VERIFY_TOKEN` | Arbitrary secret shared with Meta to verify the webhook endpoint. |
| `STRIPE_SECRET_KEY` | Stripe secret API key. |
| `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY` | Stripe publishable API key. |
| `STRIPE_WEBHOOK_SECRET` | Stripe webhook signing secret. |
| `STARTER_PLAN_ID` | Stripe Price ID for the Starter plan. |
| `PRO_PLAN_ID` | Stripe Price ID for the Pro plan. |
| `BUSINESS_PLAN_ID` | Stripe Price ID for the Business plan. |
| `GEMINI_API_KEY` | Google Gemini API key for the Pro AI flow. |
| `ANTHROPIC_API_KEY` | Anthropic API key for the Business AI flow. |
| `GROQ_API_KEY` | Reserved for Groq integrations. |
| `OPENAI_API_KEY` | Reserved for OpenAI integrations. |
